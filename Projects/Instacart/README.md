# Instacart Market Basket Analysis

Overview
End-to-end analytics project analysing customer ordering behavior and product reorder patterns using Instacart market basket data. The project combines SQL-based analytics with interactive Tableau dashboards to surface actionable business insights.

--------------------------------
Tools
- SQL (PostgreSQL, pgAdmin 4)
- Tableau Public
- Python (Jupyter Notebook)

--------------------------------

Notes
Raw Instacart datasets are intentionally excluded from this repository due to size and best practices. All analysis is performed using aggregated SQL outputs.
